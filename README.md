# Kea - a modern DHCP

<img align="right" src="doc/images/kea-logo-100x70.png"/>

Kea provides DHCPv4 and DHCPv6 servers, a dynamic DNS update module,
optional databases support (PostgreSQL, MySQL, MariaDB) that allows
storing leases, reservations and configuration data, optional RADIUS
support, optional NETCONF agent that provides a YANG/NETCONF interface
for Kea, optional support for GSS-TSIG, and a DHCP benchmarking tool
perfdhcp.

Kea is developed by Internet Systems Consortium, Inc.

The developers' website is at https://gitlab.isc.org/isc-projects/kea/.

Limitations, known issues, and feature requests can be found
at https://gitlab.isc.org/isc-projects/kea/-/wikis/known-issues-list.

management tool is available. See the
[Stork project](https://gitlab.isc.org/isc-projects/stork/) for details.
